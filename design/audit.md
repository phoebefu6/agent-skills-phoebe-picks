# Website design audit — 2026-10-15

Target: https://phoebefu6.github.io/agent-skills-phoebe-picks/

Goal: help visitors quickly understand Phoebe's taste, see the work behind each Skill, and find a relevant Skill.

| Priority | Confirmed issue | Concrete fix | Effort |
| --- | --- | --- | --- |
| High | The first six published Skills all use the same large text card, so the gallery looks repetitive and the promised artifacts are invisible until a click. | Make 2–3 featured stories with real demo previews, a one-line verdict, and a clear artifact link. Move the remaining Skills into a compact browsable list. | L |
| High | The latest Mindmap + Sites work is represented by text tiles, while its field-test cards have no preview. An unrelated hand-drawn preview becomes the strongest image in the field-test section. | Use a real Mindmap/Sites screenshot or cropped interactive preview as the hero and give every featured item a consistent media slot. | M |
| Medium | Thirteen category filters compete with search before visitors see the work. | Show 4–5 task-based categories and put the rest behind More filters; keep search visible. | M |
| Medium | The gallery says “Showing 6 of 25” beside “25 Skills,” which makes the displayed result count ambiguous. | Label the subset “6 featured picks” and the control “Browse all 25 Skills.” | S |
| Medium | Card copy repeats platform lists, long summaries, rating, built title, and source in each item; scanning requires reading paragraphs. | Keep one outcome sentence, score and source on the card; move platform and detailed review data into the existing drawer. | M |

Direction: treat the homepage as a selected-work portfolio first and a searchable catalog second. Use one large featured case study, a few varied supporting pieces, and a compact index for the full library. Maintain a stable type scale, restrained palette, visible focus, and consistent preview aspect ratios.

Evidence: reviewed live mobile hero, desktop hero and gallery, and desktop field tests on 2026-10-15. This is a visual and content hierarchy review, not a full screen-reader or WCAG audit.

Implementation status: addressed in the 2026-10-15 portfolio redesign. The page now leads with a live lab preview, has two image-led selected projects, uses a compact Skill index and grouped filters, and shows consistent preview slots for the three featured field tests. This document records the baseline that prompted the change.
