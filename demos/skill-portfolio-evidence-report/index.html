Methodology and limitations
Input parsingThe report reads window.PICKS from the gallery’s real JavaScript dataset. No rows or rating values are invented inside this page.
Metric definitionsField-tested counts all review records. Published counts status = published. Average rating is the arithmetic mean of numeric overall ratings. Primary focus uses the first scenario.
LimitationsThis is a small curated portfolio, not a market benchmark. Ratings are curator judgments after different artifact types. Repository popularity remains internal source-gate evidence and is not treated as a Skill score.
Static report UI · charts rendered from live local catalog dataChart containers use fixed heights to prevent resize loops
