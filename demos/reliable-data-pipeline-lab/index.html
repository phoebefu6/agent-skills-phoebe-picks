Failures will show the alert, retry, cleanup, and recovery decision here.

Decision

Hourly batch, not streaming

Finance accepts a 60-minute freshness target. Batch reduces platform cost and operational complexity while meeting the decision need.

Consequences

Safe replay over lowest latency

Partitioned merges, explicit watermarks, atomic publishing, and one active run make retries and backfills predictable.

Recovery

Retry, quarantine, then alert

Transient failures retry exponentially. Data failures stop publication, preserve evidence, run cleanup, and page the owner.
