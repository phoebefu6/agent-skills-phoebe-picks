Top level

The top level of JSON Canvas contains two arrays:

  • nodes — objects on the canvas
  • edges — connections between nodes

Nodes

Text, file, link, and group nodes share an ID, type, position, and dimensions. Array order determines their z-index.

Edges

Edges reference valid source and target IDs, with optional sides, endpoint shapes, labels, and colors.

Color

Colors use either a hex string or one of six portable preset values.
