# From Skill Source to Published Artifact

## Overview

A public registry for agent-usable coding Skills: instruction packs, implementation playbooks, and reusable workflows that Codex and Claude Code can use to build real software artifacts.

## Learning Objectives

The viewer will understand:

1. What Digest Skills with Phoebe catalogs.
2. How the four-step publishing loop moves from source to improvement.
3. What Baoyu Infographic contributes to today’s experiment.

## Design Instructions

### Style Preferences

- Reuse the website palette: warm paper, near-black ink, coral, sun yellow, mint, cyan, and violet.
- Favor friendly hand-drawn education marks with crisp, legible typography.
- Keep illustration secondary to information.

### Layout Preferences

- Landscape 16:9 for website embedding.
- Use one left-to-right linear progression with a visible return loop.
- Keep all text away from the outer crop boundary.

### Other Requirements

- Generated through the project-local Baoyu Infographic workflow.
- No logos or copied proprietary brand assets.
- No watermark.
