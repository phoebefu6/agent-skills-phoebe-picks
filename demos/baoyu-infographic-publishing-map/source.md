# From Skill Source to Published Artifact

## Digest Skills with Phoebe

A public registry for agent-usable coding Skills: instruction packs, implementation playbooks, and reusable workflows that Codex and Claude Code can use to build real software artifacts.

The site currently has 50 seeded capability entries.

## The Publishing Loop

### 01 Source

Skill name, official GitHub link, and official description are shown first so readers know where the tool comes from.

### 02 Artifact

Each skill gets a tangible outcome that uses the core 80 percent of the skill's day-to-day functions.

### 03 Life Impact

Three practical points explain how the skill saves time, improves decisions, or reduces daily friction.

### 04 Improve

Three iteration notes keep the skill alive: prompts, templates, benchmarks, automations, or better product polish.
